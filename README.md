# ConvoFlow

Código do aplicativo web do [ConvoFlow](https://www.convoflow.com.br): React 18,
TypeScript e Vite, com backend no Supabase.

Este repositório é uma **cópia de publicação**: é daqui que o site é compilado e
publicado. Cada commit é a fotografia de uma versão já revisada; o
desenvolvimento acontece em outro lugar, e pull requests aqui não são
aproveitados.

## Rodar localmente

```bash
npm ci
npm run dev        # servidor de desenvolvimento na porta 8080
npm run build      # build de produção (exige VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY)
npm run test:run   # testes
```

## Segurança

Achou uma falha? Escreva para contato@convoflow.com.br — não abra issue pública.
